# Changelog

## [v3.2.0] - Dashboard Responsivo, SEO y Nuevas Secciones

### ✨ Nuevas Funcionalidades
- **Dashboard Premium**: Refactorización completa del `index.html` con un nuevo diseño premium utilizando Tailwind CSS, ahora completamente responsivo.
- **Sección de Mapas**: Integración de una nueva sección de Mapas Conceptuales en el menú lateral para un acceso rápido a los resúmenes visuales.
- **Buscador Integrado**: Implementación de una barra de búsqueda para encontrar rápidamente recursos y diapositivas.
- **Mejoras de Navegación Móvil**: Menú optimizado para dispositivos móviles, facilitando la navegación entre módulos y juegos.

### 🔧 Mejoras (Mejoras y SEO)
- **SEO Optimizado**: Adición de `robots.txt` y etiquetas `meta description` a los diferentes índices de actividades y diapositivas de módulos para mejorar el posicionamiento.
- **Diseño Responsivo en Diapositivas**: Refactorización completa de los módulos 1 al 6, asegurando que todas las diapositivas se vean de manera óptima en dispositivos móviles, ajustando `aspect-ratio`, anchos, alturas y `overflow`.
- **Actualización de README**: Documentación principal actualizada con las nuevas características del dashboard.

### 🎮 Juegos y Módulos de Ejercicios
- **Space Shooter**: Integración de nuevas preguntas dinámicas para los quizzes en Moodle.
- **MathQuest**: Refinamiento y consolidación de los módulos con nuevos formatos de preguntas.
- **Flashcards**: Inclusión de preguntas detalladas y estructuradas cubriendo múltiples conceptos matemáticos para cada módulo.

### 🐛 Correcciones
- Solución de problemas de visualización y desbordamiento (overflow) en múltiples diapositivas interactivas (Módulo 1 al 6).
- Correcciones de estilos CSS en dispositivos móviles y resoluciones no estándar.
